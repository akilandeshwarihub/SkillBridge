# SkillBridge – Education & Career Guidance

## About the Project
SkillBridge is a simple and modern education and career guidance website built using HTML and CSS. It helps users explore popular courses and career opportunities.

## Technologies Used
- HTML5
- CSS3

## Features
- Clean and modern design
- Popular courses section
- Career opportunities section
- Simple and user-friendly layout

## Project Structure
- `index.html` – Website structure
- `style.css` – Website styling

## Project Objective
The objective of this project is to create a simple website that provides basic information about education, courses, and career opportunities.

## Developer
Created as a beginner-friendly web development project.
